药物 ATC 映射 DeepAgent 框架流程

deepagents 动态运行时 · 本地 Chroma 分片 RAG · 多源证据融合 · 批量评测（示意：结构与真实代码一致）

一、整体架构（四层）

从入口到数据源的分层结构，各层通过统一接口连接。
入口层
test-deepagents.py（单药）· experiments/run_deepagents_dataset.py（批量评测）
Agent 层
DeepATCAgent → create_deep_agent（deepagents 0.7.x），动态规划工具调用 + Skills 只读 + 反思精化
工具层
6 个只读工具：翻译 / WHO 搜索 / WHO 核验 / PubChem / Tavily / 本地 RAG
数据层
deepseek-chat（LLM）· Chroma 17 分片（6807 条）· bge-m3（1024 维）· 外部 API（WHO/PubChem/Tavily/百度翻译）

二、离线知识构建（RAG 灌库，一次完成）

ATC 知识源 → 清洗组装 → 向量化 → Chroma 分片落盘。产出 data/vector_db（17 分片 / 6807 条）。
① ATC.csv
data/knowledge/ATC.csv，6807 条
→
② 列映射 + 清洗
build_vector_db.py 自动识别列名、去空行
→
③ 组装知识文档
“药物: X，ATC 编码: Y，相关信息: …”
→
④ bge-m3 向量化
本地模型，1024 维，分批 100 条/次
→
⑤ Chroma 分片存储
400 条/片 ×16 + 407 = 17 片（不足 100 并入，避免小分片无法落盘）
→
⑥ 等待索引落盘
compactor 异步写 HNSW，等待 300 秒（进程内不得重开 client）
→
⑦ data/vector_db
chroma.sqlite3 + 17 个分片集合，检索时合并排序
为何分片：本机 chromadb 对超大单集合的 HNSW 索引无法落盘（报 Error loading hnsw index），≤500 条的分片可正常落盘，故按 400 条/片存储，查询时遍历各片合并后取 TopK。

三、在线 ATC 映射（DeepAgent 动态流程）

输入药物名 → Agent 按证据缺口动态调用工具 → LLM 推理 → 反思精化 → 输出可审计结果。
输入药物名
如 “阿司匹林”
→
Agent 分析
判断是否需翻译 / 是否有歧义
→
动态工具循环
每轮只调用解决当前证据缺口的工具，按优先级
→
LLM 推理
deepseek-chat，输出规定 JSON（编码 + 置信度 + 依据）
→
反思门无候选 / 编码格式非法 / 最高置信度 < 0.80 → 再推理 1 轮（≤1 轮）
↺
输出结果
主编码 / 全部编码 / 证据源 / 人工核验标记
工具失败自动降级：外部 API 报错 → 结构化错误返回 Agent → Agent 换策略或靠 WHO / 本地 RAG 兜底，不中断流程。

6 个工具与优先级

search_who_atc高优先
WHO ATC 官方索引按名查候选编码
validate_who_atc高优先
核验每个 7 位编码及其官方层级
search_local_atc_knowledge辅助
本地 RAG：bge-m3 查询 → 17 分片合并 → TopK
search_pubchem辅助
药物性质 / 别名 / ATC 相关信息
translate_drug_name前置
中文名 → 英文检索名（百度翻译）
search_tavily低优先
网络搜索补充背景，不能覆盖 WHO 结论

四、批量评测流程（数据集级）

对整张药物表批量映射并产出指标报告，支持断点续跑与缓存隔离。
① 选择数据集
gdph（中文）/ pyxis（MIMIC）/ healthcanada 等
→
② run_deepagents_dataset.py
缓存隔离 + --limit / --resume 断点续跑
→
③ 逐药映射
复用 DeepATCAgent，结果即时写 JSONL
→
④ 指标计算（metrics.py）
三分类 exact/partial/none + F1 宏平均 + Top1 + 覆盖率 + 幻觉率
→
⑤ 报告产出
results/deepagents/_report.xlsx + predictions.jsonl
F1＝2·P·R/(P+R)，按药物宏平均（集合级，惩罚漏码/多码） Top1＝第一个预测编码命中金标准 Exact＝预测集合==金标准集合 Halluc＝预测编码不在 WHO 知识库的比例
实测参考（pyxis 50 药）：F1 0.838 · Top1 0.940 · Exact 0.720 · 幻觉 0 · 需人工核验 10%。
